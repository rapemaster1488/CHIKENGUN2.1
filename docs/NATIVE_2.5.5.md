# CHIKENGUN 2.5.5 — чёрные полосы и лаги (нативно)

Правки для нативного клиента (`./run.sh` → `build/MyShooter`). Проект живёт только
в нативном виде с 2.5 (веб-версия выведена), поэтому всё ниже — про `src/MyApp.cpp`
и шейдеры Urho3D.

## 1. «Чёрные полосы на арене и на полигоне»

Два прошлых хотфикса (2.5.3 и 2.5.4) делали одно и то же: поднимали константный
bias теней (`0.00018` → `0.00042`). Это симптоматическое лечение, поэтому полосы
возвращались.

**Настоящая причина** — shadow acne, и правильный инструмент в Urho3D 1.9.0 уже
есть: `BiasParameters(constant, slope, normalOffset)`, где третий аргумент — сдвиг
сэмпла глубины по нормали поверхности. У нас он всегда был равен `0.0`.

**Что сделано:**

| Что | Было | Стало |
|---|---|---|
| normal offset | `0.0` (выключен) | `0.0012` |
| константный bias | `0.00042` | `0.00022` |
| slope bias | `0.60` | `0.55` |
| каскады | захардкожены в одной функции | `GameConstants::SHADOW_SPLITS` |
| настройка при смене пресета | не перенастраивалась | `ConfigureSunShadows()` |

Дополнительно в `Lighting.glsl` и `Lighting.hlsl` добавлено:

```glsl
#if defined(SHADOW) && !defined(NORMALOFFSET)
    #define NORMALOFFSET
#endif
```

Без этого движок не выберет вариант шейдера с нормальным сдвигом
(`Renderer.cpp`, `LVS_SHADOWNORMALOFFSET` / `DLPS_SHADOWNORMALOFFSET`) — вариант
существует только при `GetShadowBias().normalOffset_ > 0`.

Масштаб сдвига не наш: движок берёт размер каскада (`Batch.cpp`) и присылает
`cNormalOffsetScale`, поэтому своих магических констант в шейдере нет.

### Если рябь всё же останется на конкретной поверхности
- поднять `SHADOW_NORMAL_OFFSET` до `0.002` (мировой масштаб, каскады сами домножат);
- сузить дальний каскад: `SHADOW_SPLITS[3] = 128.0f`;
- проверить, что объект не тонкая плоскость (у листа normal offset даёт утечку).

## 2. «Лагает»

### 2.1 HUD перестраивал геометрию текста каждый кадр
`Text::SetText()` в Urho3D **всегда** выполняет `DecodeToUnicode()` +
`UpdateText()`, даже если строка не изменилась. HUD вызывал его каждый кадр для
телеметрии, патронов, HP, счёта, точности и баффов.

Теперь `SetTextIfChanged()` / `SetColorIfChanged()` сначала сравнивают значение.
Телеметрия дополнительно считает FPS по окну 0.25 с (мгновенный `1/dt` скачет на
±30% и обновлял текст почти каждый кадр) и показывает худший кадр окна.

### 2.2 Авто-адаптация качества `[F7]`
Каждые 2 секунды измеряется средний кадр. Если стабильно ниже ~45 FPS, снимается
ровно один шаг нагрузки:

```
SSAO4K → тени 2K → MSAA 2x → пресет ВЫСОКИЙ → тени off → bloom off
```

Никогда не повышает обратно (никаких «качелей»), сообщает в чат, что снизил, и
сохраняет флаг в `settings.ini`. Выключить можно `F7`.

### 2.3 Что ещё проверить, если лагает на 4K
- `F3` — телеметрия: FPS, худший кадр, треугольники, батчи, разрешение теней;
- `F9` — пресет: 4K ULTRA с SSAO + 4K-тени выключит авто-адаптив сам;
- лимит кадров в настройках (60/120/240/без лимита).

## 3. «Полигон»

- **Утечка узлов.** При респавне мишени удалялся коллайдер, но не узел модели:
  каждая новая мишень оставляла невидимый `StaticModel`. На длинной сессии сцена
  копила сотни нод. Исправлено.
- **Мишени за спиной.** Новая мишень ставилась в случайную точку 30×30 м и могла
  оказаться за игроком или внутри декора. Теперь — в секторе ±60° перед камерой,
  9–17 м, с прижимом к границам арены.
- Коллайдеры мишеней/врагов чистятся корректно (`RemoveColliderLite` +
  `CompactColliders`) — проверено, утечки здесь нет.

## 4. Проверка

```bash
# полная проверка типов против заголовков Urho3D (-Werror)
URHO3D_HOME=/path/to/urho3d ./tools/syntax_check.sh

# реальный запуск
./run.sh
```

В игре: вращение камерой на арене и на полигоне — грани без чёрных полос,
`F3` показывает FPS и `SHADOW: on normal-offset`.

Проверено в песочнице: `syntax_check.sh` против Urho3D **1.9.0** и **master**
(0 предупреждений при `-Werror`), 311 XML, `tests/test_build_scripts.sh`,
препроцессор GLSL/HLSL для всех вариантов `NORMALOFFSET`.

**Ограничение:** нативный клиент не линкуется в песочнице (нет OpenGL/SDL
рантайма), поэтому «полосы ушли» окончательно подтверждается только запуском
на целевой машине.
