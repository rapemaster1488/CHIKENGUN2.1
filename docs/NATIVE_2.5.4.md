# CHIKENGUN 2.5.4 — нативные хотфиксы (Urho3D, `src/MyApp.cpp`)

Баги от игрока, найденные и исправленные в нативном клиенте (`./run.sh` → `build/MyShooter`):

1. **«Загрузочный экран не поменял»** — нативный экран загрузки остался из эпохи 2.2
   (захардкожено `CHIKENGUN 2.2`, «4K ULTRA EDITION»). Переписан под 2.5 «ПЕРО СУДЬБЫ»:
   - заголовок `CHIKENGUN 2.5`, подзаголовок `ПЕРО СУДЬБЫ | CYBER ARENA`;
   - этапы и чек-лист отражают реальные подсистемы (HDR/ACES/CAS, PBR-текстуры, Sky4K,
     арена 256×256, тени 4K, волны 2.5 «ПЕРО СУДЬБЫ»);
   - золотые пернатые акценты (плашка над заголовком вместо красной), версия движка в теге сверху;
   - фон `Data/Textures/LoadingBg4K.png` и прогресс-бар с переливом сохранены.

2. **«Весь экран жёлтый при перезарядке»** — в нативке был полноэкранный
   `reloadOverlay_` (`BorderImage`, `BLEND_ADD`, `Color(1.0, 0.9, 0.1)`) с альфой
   `0.25 + 0.18·sin(10t)` каждый кадр, пока идёт перезарядка. Удалён полностью:
   мембер, создание, пульс, сброс в `CompleteReload()` и `SetVisible` в фото-режиме.
   Перезарядка по-прежнему видна по HUD (сообщение «Перезарядка…», счётчик патронов).

3. **«Чёрные полосы/рябь на поверхностях при вращении камеры»** — классический
   shadow acne на 4-каскадных тенях солнца (карта 2048–8192, каскады 14/38/88/165 м):
   - было `SetShadowBias(BiasParameters(0.00018f, 0.42f))` — константное смещение ниже
     стокового дефолта Urho3D, почти без slope-scaled составляющей;
   - стало `BiasParameters(0.00042f, 0.60f)` (≈10 см на дальних каскадах + 0.6·наклон) —
     полосы уходят, заметных утечек света на планарных поверхностях нет.

   Если «рябь» вернётся на конкретных поверхностях:
   - поднимите константный bias до `0.0006f` (ценой peter-panning на тонких объектах);
   - либо сузьте дальний каскад (`CascadeParameters(14, 38, 88, 128.0f, 0.82f)`);
   - либо выставьте `shadowcull` на игровых материалах в XML (`Data/Materials/Game/*.xml`,
     атрибут `<shadowcull value="cw"/>`), чтобы в depth-pass писались только передние грани;
   - `SetShadowIntensity(0.18f)` уже делает тени мягкими — не поднимайте, полосы только заметнее.

## Проверка
Нативный клиент не собирается в CI (нужен Urho3D + OpenGL). Локальная проверка:

```bash
./run.sh     # сам соберёт build/MyShooter, если устарел
```

В игре: запуск → экран «CHIKENGUN 2.5 / ПЕРО СУДЬБЫ»; `R` — перезарядка без жёлтого залива;
вращение камеры мышью — ровные грани без чёрных полос.

## Известные ограничения
- Shadow acne лечили bias'ом, а не back-face depth-pass'ом: back-face уберёт рябь полностью,
  но оторвёт тени от тонких объектов (столы, столбы). Если попросите — переключу.
- Нативный билд не прогонялся в sandbox (нет Urho3D/OpenGL); проверка на целевой машине обязательна.
