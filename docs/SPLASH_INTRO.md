# 2.5.5 — Эпичная интро-заставка нативного клиента

При запуске `./run.sh` перед загрузочным экраном появляется заставка студии
(чёрный фон, надписи в такт музыке, ~5 секунд, **пропуск — клик / Space / Enter / Esc**):

| Время | Кадр | Что звучит |
|-------|------|------------|
| 0.0–1.3 c | **koch.studios** (строчные, неоновый циан, буквы fade-in + раскрывающаяся линия) | тёмный райзер + суб-дрон D, сердцебиение, клик UI_Select |
| 1.3–2.5 c | **powered by fall.os** (мелким серо-голубым, «fall.os» приземляется) | мягкий боом + пад + стеклянные колокола, поверпап Powerup |
| 2.5–5.05 c | **CHICHKENCUM 2.1** (вспышка белого → золото, сләм) | SLAM + петушиный клич (Chicken_Boss.wav) |

После заставки обычная фаза загрузки «CHIKENGUN 2.5 / ПЕРО СУДЬБЫ» продолжается:
интро-тема **не обрывается**, а плавно затухает вместе с экраном загрузки,
после чего вступает основная петля арены (`Music/Game_Theme_Loop.ogg`).

## Музыка — `Data/Music/KochSplashTheme.wav` (15.2 c, 44.1 кГц, стерео, PCM 16-bit)

Собрана синтезатором из `tools/gen_splash_theme.py` (numpy + soundfile):

- **0.0–1.3 с** — чёрный райзер (шумовой свип), суб-дрон D2, «сердцебиение» боомами;
- **1.3 с** — удар «fall.os»: низкий спад, пад Dm, колокола D5–A5–F5;
- **2.5 с** — SLAM «CHICHKENCUM 2.1»: взрыв с тарелкой + стаккато-брасс Dm;
- **2.5–6.5 с** — грув A (Dm–Bb–Gm–A): 4-на-полу кик, бас-осцинатор 8-ми, стэбы брасса, хэты;
- **6.5–8.15 с** — слом: половина темпа, тайко, райзер;
- **8.15–12.8 с** — кульминация: удвоенный кик + пилящая соло-партия (A A G F E D C D…);
- **12.8 c** — финальный удар tutti + реверб-хвост.

Тональность D minor, 140 BPM. Пиковый уровень −0.55 dBFS (tanh-лимитер, общий пик 0.94).
Почему WAV, а не OGG: связка `libsndfile → Vorbis` в генераторе портит амплитуду
(выходной пик читался как 2.34 при записанных 0.94) — WAV гарантированно корректен
и нативно грузится Urho3D, как и остальные `Data/Sounds/*.wav`.

Перегенерация: `python3 tools/gen_splash_theme.py` (нужны `numpy`, `soundfile`).

## Что изменено в коде (`src/MyApp.cpp`)

- новые члены: `splashActive_`, `splashStage_`, `splashTimer_`, `splashPanel_`,
  `splashText_`, `splashLine_`, `splashScene_`, `kochMusicNode_`,
  `kochThemeSrc_`, `splashSfxSrc_`;
- `CreateSplashIntro()` — чёрный UI-панель `SetPriority(1200)` поверх загрузочного экрана (1000),
  надпись + «раскрывающаяся» неоновая линия, временная сцена с двумя SoundSource
  (музыка + SFX) — главная сцена игры создаётся лишь на шаге 3 загрузки;
- `UpdateSplashIntro()` — конечный автомат стадий (fade через smoothstep, easeOutQuad
  для линии, вспышка белым «CHICHKENCUM» с остыванием в золото за 0.55 с);
- `SplashEnterStage()` — SFX на каждую стадию (UI_Select → Powerup → Chicken_Boss);
- `EndSplashIntro()` — снимает панель; музыка продолжает звучать в фазе загрузки;
- `StartAmbientLoop()` — вступление основной петли после затухания интро-темы;
  `LoadAudioAssets()` больше не запускает `Game_Theme_Loop` поверх интро (`!kochThemeSrc_`);
- `UpdateBootLoading()` — fade-блок экрана загрузки дополнительно гасит громкость интро-темы;
- `HideLoadingScreen()` — стоп интро-темы, удаление временной сцены, старт основной петли.

## Проверка

`g++ -fsyntax-only` и полный `g++ -c` против хидеров Urho3D (master, GraphicsAPI-раскладка) —
чисто, ноль диагностик. CI нативный клиент не собирает; финальная проверка на целевой машине:

```bash
./run.sh
```

Ожидается: чёрный экран → «koch.studios» → «powered by fall.os» → «CHICHKENCUM 2.1»
с петушиным кличем → загрузочный экран 2.5 с догорающей интро-темой → главное меню.
Заставка пропускается кликом или Space/Enter/Esc.
