# 2.5.6 — Интро-заставка нативного клиента «koch.studios → fall.os → CHICHKENCUM 2.1»

Запуск: `./run.sh`. Перед загрузочным экраном ~4.5 секунд чёрного экрана с надписями, всё в такт музыке. **Скип: клик / Space / Enter / Esc.**

## Что было исправлено по сравнению с первой версией 2.5.6

| Проблема | Исправление |
|---|---|
| Строка «печаталась» и **прыгала в стороны** (HA_CENTER + растущий Substring → пересчёт центра каждый кадр) | Каждая буква — **отдельный Text**, позиции вычислены один раз через скрытый «измеритель» (`GetCharPosition`) → строка больше **не двигается ни на пиксель** |
| Блик был **белой полосой-прямоугольником** без текстуры | Текстура `Data/Textures/SplashSheen.png` — мягкая золотая полоска (additive), проходит по строке с easeInOut |
| CHICHKENCUM **дёргался тряской** | Тряска убрана совсем; остались наезд размера `SF(96)→SF(76)` (easeOutExpo) и вспышка белого → золото |
| Печатание было дёрганным, без волны | Буквы выплывают **волной слева направо** (задержка по индексу 42 мс), подъём easeOutExpo + мягкое дыхание в покое |
| Музыка звучала «синтвейвом» и утомляла | **Полностью новая оригинальная тема**: felt piano + гармонь + щипковый бас, дождь/ветер/винил, реальная форма A minor (Am–Dm–E7–F), динамика от −28 до −5 dB вместо ровных −3 dB |
| Вступление длилось ~5 с | Ритм ускорен: ~4.5 с всего |

Общие приёмы (все стадии):
- **выплывание снизу** на `easeOutExpo` (46 px → 0) + деликатное «дыхание» (`sin`, 2 px) в покое;
- **посимвольное выплывание** строк 1–2: задержка `0.10 + index * 0.042`, подъём easeOutExpo, альфа easeOutCubic;
- **неоновое свечение** за текстом (`Data/Textures/SplashGlow.png`, additive, тинт стадии: циан / осенне-оранжевый / золото; пульс 1.9 Гц, альфа ≤ 0.46);
- **волна-блик** пробегает по строке в середине стадии (easeInOutQuad, альфа ≤ 0.52);
- неоновая линия раскрывается от центра (`easeOutQuad`, задержка 0.14 с);
- стадия 3: наезд размера `SF(96) → SF(76)` за 0.30 с, вспышка белого остывает в золото за 0.6 с.

## Музыка — оригинальная осенняя меланхолия, `Data/Music/KochSplashTheme.wav`

Меланхоличный шансон в A minor, 3/4, 96 BPM (~16.6 с, продолжается в фазе загрузки как и раньше):

- **гармонь** — треугольники из 3 синусов + второй голос ниже на ~5 центов, тремоло 5.2–5.4 Гц, вибрато 5.1 Гц, полоса 210–2450 Гц;
- **felt piano** — рояль под войлок: синус + частичные 2/3/4 с затуханием (2.1/3.4/5.2/7.0 с⁻¹), без единой пилы;
- **щипковый бас** (корень на такт) + мягкий кик и щётки со 2-й фразы, taiko на акцентах;
- **дождь, ветер, винил** — воздушная подкладка всё произведение;
- форма: такты 3–9 (Am–Dm–E7–Am–F–E7–Am), мелодия поёт «издалека» и разворачивается к финалу;
- конволюционный реверб (2.6 с, полоса 140–6800 Гц) + мягкий tanh-лимитер, пик −1 dBFS.

Перегенерация: `python3 tools/gen_splash_theme.py` (нужны `numpy`, `soundfile`).

### Своя музыка вместо синтезированной
«Какая осень в лагерях» — чужое произведение: в репозиторий не вшивается. Если у тебя есть **лицензионная** копия (или любая другая музыка, которую ты вправе использовать):

```bash
cp /путь/к/треку.wav Data/Music/KochSplashTheme.wav
git update-index --skip-worktree Data/Music/KochSplashTheme.wav
```

Формат — любой WAV/OGG, который грузит Urho3D. Идеально, если в треке есть удар в районе 2.5 с — он совпадёт со вспышкой «CHICHKENCUM 2.1».

## Что изменено

- `src/MyApp.cpp`: посимвольный выплывающий рендер (скрытый «измеритель» + `GetCharPosition` + отдельный `Text` на букву), наезд `SF(96→76)` без тряски, золотой блик-текстура `Textures/SplashSheen.png`;
- `Data/Textures/SplashGlow.png` — неоновый ореол (генерируется `tools/gen_splash_glow.py`);
- `Data/Textures/SplashSheen.png` — мягкий блик (генерируется однострочным PIL-скриптом, см. код в git-истории);
- `Data/Music/KochSplashTheme.wav` — новая оригинальная осенняя тема (felт piano + гармонь);
- панель `KochSplashIntro` с `SetPriority(1200)` поверх загрузочного экрана.

Проверка: `g++ -c src/MyApp.cpp` против реальных хидеров Urho3D — ноль ошибок (класс компилируется только так; у репозитория нет CI для нативного клиента — финальный вид смотри `./run.sh`).
