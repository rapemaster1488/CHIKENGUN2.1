# Native Desktop Guide: сборка и запуск CHIKENGUN 2.5

Проект полностью перешёл на единый **нативный C++17 / Urho3D desktop-клиент** (`src/MyApp.cpp`).
Браузерная версия и веб-лаунчеры удалены — вся функциональность (арена 2.5 «ПЕРО СУДЬБЫ», 12 видов оружия, 4K PBR, «Кочет в баньке», «Золотая Рулетка» + «Кибер-Слоты 777», «Pixel Arcade» на 6 мини-игр) живёт внутри нативного бинарника `build/MyShooter`.

---

## Быстрый старт в одну команду (без ручной возни с Urho3D)

```bash
git clone https://github.com/rapemaster1488/CHIKENGUN2.1.git
cd CHIKENGUN2.1

# На чистой машине (поставит системные пакеты, сам соберёт минимальный Urho3D в .cache/urho3d-sdk,
# сгенерирует PBR-текстуры/звуки и запустит игру):
./run.sh --install-deps
```

Все последующие запуски — мгновенно без пересборки Urho3D:

```bash
./run.sh
```

### Полезные флаги сборки (`./build.sh` и `./run.sh`)

- `./run.sh --4k` / `./build.sh --4k` — генерация полного 4096×4096 набора PBR-текстур + 3840×2160 `LoadingBg4K.png` (по умолчанию `TEX_SIZE=1024` для быстрого старта на любой машине).
- `./build.sh --install-deps` — автоустановка системных пакетов сборки под `apt`, `dnf`, `pacman`, `zypper` или `brew`.
- `./build.sh --tests-only` — мгновенная сборка и прогон модульных C++17 тестов (`test_core`) без Urho3D.
- `URHO3D_HOME=/путь/к/sdk ./build.sh` — использовать уже установленный в системе Urho3D вместо скачивания.
- `./tools/package_linux.sh` — собрать автономный переносимый архив `build/release/CHIKENGUN-2.5-Linux-x86_64.tar.gz` (работает на другом ПК вообще без компилятора).

## Альтернативная сборка через CMake

CMake также умеет автоматически подтягивать Urho3D 1.9.0 через `FetchContent` (`AUTO_FETCH_URHO3D=ON` по умолчанию):

```bash
cmake --preset desktop
cmake --build --preset desktop
```

Без пресетов (для CMake 3.16+):

```bash
cmake -S . -B build-desktop -DBUILD_GAME=ON -DAUTO_FETCH_URHO3D=ON
cmake --build build-desktop -j
```

Только headless-тесты (без OpenGL/SDL2/Urho3D):

```bash
cmake -S . -B build-tests -DBUILD_GAME=OFF
cmake --build build-tests -j
ctest --test-dir build-tests --output-on-failure
```

## Что проверять вручную в клиенте

1. **Меню**: `W/S` выбирают пункт, `Enter` запускает, `Esc` выходит.
2. **Полигон и Арена 2.5 «ПЕРО СУДЬБЫ»**:
   - Неоновый ритуальный круг с взлётными полосами в центре, 4 hazard-ежа, 2 северные/южные арки, вентили на трубах.
   - Оружие 1–9 / 0 / `[` / `]`, цвет перекрестия под цвет ствола, полоса прогресса перезарядки.
   - Живое поведение кур (weaving при сближении, выпад клювом, падение и исчезновение трупов через 3.5 сек) + счётчик оставшихся врагов текущей волны в HUD.
3. **Кочет в баньке `[P]`**: сруб на 3D-арене и в меню, градусник пара и снег за окном, действия `1..5`, загадки `Q/W/E/R`, статистика `6`, 14 концовок и боевые баффы Арены.
4. **Казино `[J]`**: переключение `[TAB]` между **Золотой рулеткой** (с историей последних 10 спинов) и **Кибер-Слотами 777** (выплаты до `×50`).
5. **Pixel Arcade `[K]`**: все 6 игр — `[1] Змейка`, `[2] Арканоид`, `[3] Куро-Ран`, `[4] Pong`, `[5] Flappy Кочет`, `[6] Кибер-Тетрис` (начисление кредитов `¤` за результаты).
6. **Горячие клавиши**: `F1`–`F3`, `F8`, `F9`, `F11`, `F12`, ресайз окна и `settings.ini` в пользовательской директории Urho3D (`GetAppPreferencesDir`).
