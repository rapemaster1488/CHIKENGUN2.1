# ЧТО ЭТО ЗА ХУЙНЯ?
ChickenGun — результат коллективной лоботомии разработчиков, проведённой в подвале ветеринарной клиники без анестезии и лицензии.
Проект создавался людьми, у которых медицинская карта толще исходного кода.
По неподтверждённым данным, после запуска игры у пользователей наблюдаются:
- Острая куриная недостаточность.
- Терминальная стадия долбоебизма.
- Хроническое желание стрелять по птицам.
- Прогрессирующая атрофия здравого смысла.
- Синдром фантомного яйца.
- Аллергия на нормальный геймплей.
Внимание: перечисленные заболевания вымышлены. Однако качество кода вызывает реальные вопросы.

## Сборка

Что нужно:

- **Urho3D** (заголовки + `libUrho3D.so`). `build.sh` ищет их в `$HOME/urho3d/build/include`,
  `/usr/local/include/Urho3D`, `/usr/include/Urho3D`; свой путь можно задать вручную:
  `URHO_INC=/путь/к/include ./build.sh`
- SDL2 (`libsdl2-dev`), OpenGL/X11, g++ с C++17.

```bash
./build.sh                 # соберёт build/MyShooter и синхронизирует ресурсы в build/Data
```

## Запуск

Бинарник кладётся в `build/`, ресурсы — в `build/Data` (туда их копирует `build.sh`):

```bash
./build/MyShooter
```

## Управление

| Клавиша | Действие |
|---|---|
| `WASD` | движение |
| `SHIFT` | бег (из приседа не работает) |
| `SPACE` | прыжок (есть coyote-time и буфер прыжка) |
| `CTRL` / `C` | присед |
| `ЛКМ` | огонь (авто у большинства стволов) |
| `ПКМ` | прицеливание (ADS) |
| `R` | перезарядка |
| `1..7` | выбор оружия (у каждого свой боезапас) |
| `Q` / `E` | скин оружия |
| `TAB` | арсенал |
| `F` | смена режима тир ⇄ арена |
| `ESC` | пауза (`ESC`/`ENTER` — продолжить, `M` — в меню, `Q` — выход) |

Зелёные сферы на арене — аптечки (+25 HP), жёлтые — патроны. Подбор автоматический.

## Настройки

Меню → «НАСТРОЙКИ»: тени (1K/2K/4K), HDR Bloom, лимит FPS, фильтрация текстур,
громкость эффектов и музыки. Сохраняются в `settings.ini` рядом с бинарником вместе с рекордом.
