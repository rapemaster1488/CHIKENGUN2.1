# CHIKENGUN 2.5 — ПЕРО СУДЬБЫ (Native Desktop C++17 / Urho3D)

> **100% нативный кросс-платформенный C++17 / Urho3D 3D-шутер** (NixOS/Nix, Linux, macOS, Windows). Веб-версия полностью выведена из проекта — весь геймплей, 4K PBR-арена, интро 2.5.6, баня, казино со слотами 777 и все 6 мини-игр Pixel Arcade работают в едином нативном desktop-приложении.

## Быстрый старт на любой ОС

### Nix / NixOS
```bash
nix run                  # Flakes: собрать, проверить тесты и сразу запустить
nix develop -c ./run.sh  # Dev-окружение с готовым Urho3D 1.9.0 SDK
nix-shell --run ./run.sh # Классический nix-shell (без Flakes)
```

### Linux (Ubuntu/Debian, Fedora, Arch, openSUSE, Alpine, Void) и macOS (Intel / Apple Silicon)
```bash
git clone https://github.com/rapemaster1488/CHIKENGUN2.1.git
cd CHIKENGUN2.1
./run.sh --install-deps   # поставит системные пакеты, закэширует Urho3D 1.9.0 и запустит игру
```

После первого запуска:
```bash
./run.sh                   # мгновенный запуск (пересобирает только при изменении src/*)
./run.sh --4k              # собрать полный 4K UHD набор PBR-текстур (4096×4096) и запустить
./run.sh --diagnose-sdl    # Linux: проверить встроенный SDL, дисплей, OpenGL и аудио
./run.sh -nosound          # запустить без звука
./tools/package_linux.sh   # упаковать автономный .tar.gz для запуска на другом Linux без компилятора
```

Тени, SSAO и производительность (чёрные полосы, просадки FPS, полигон) разобраны
в [заметках 2.5.5](docs/NATIVE_2.5.5.md): нормальный сдвиг теней вместо подкрутки
bias, авто-адаптация качества по `F7` и телеметрия по `F3`.

Если окно не открывается, запускайте игру из графической X11/Wayland-сессии: без доступного дисплея подставной видеодрайвер не создаёт игровое окно. При отсутствии аудиоустройства Linux-клиент продолжит работу без звука. Диагностика и пересборка SDL описаны в [руководстве](docs/DESKTOP_BUILD.md#диагностика-sdl-на-linux).

### Windows (PowerShell / Visual Studio / MSVC)
```powershell
.\run.bat                  # соберёт/закэширует Urho3D 1.9.0 (OpenGL) и запустит MyShooter.exe
.\build.ps1 -Ultra4K       # текстуры 4096x4096
.\build.ps1 -TestsOnly     # быстрые C++17 модульные тесты
```

Подробнее о флагах и сборке через CMake с локальным Urho3D SDK — в [`docs/DESKTOP_BUILD.md`](docs/DESKTOP_BUILD.md).

## Что внутри нативного клиента CHIKENGUN 2.5 / 2.5.6

### 1. Кинематографичное интро (`koch.studios` → `powered by fall.os` → `CHICKENCUM 2.1`)
- Медленное посимвольное появление, золотые ореолы, световая волна, частицы и плавный переход к загрузке и меню. Заставка длится около 15,5 с под оригинальную осеннюю тему `Data/Music/KochSplashTheme.wav` ([подробнее](docs/SPLASH_INTRO.md)). Скип: клик / `Space` / `Enter` / `Esc`.

### 2. Боевая 3D-арена 256×256 «ПЕРО СУДЬБЫ»
- **Архитектура карты**: центральный ритуальный круг (циан + золото) с 4 взлётными световыми полосами, 4 диагональных hazard-ежа с коллайдерами, 2 неоновые арки-ворота (`z = ±40`), технический балкон, магистральные трубы с вентилями, 4 гравитационных джамп-пада и 3D-сруб **«Банька Смотрящего»**.
- **9 наборов PBR-текстур + Skybox4K IBL + Post-Process стек** (`SSAO4K` + `BloomHDR` + `Cinema4K` ACES Filmic & CAS + `FXAA3`), 4 пресета погоды с 3D-частицами (`[F8]`).
- **6 пород кур с живым ИИ**: `MELEE` (петляние восьмёркой при сближении + выпад клювом), `CHARGER`, `SHOOTER`, `KAMIKAZE`, летающий дрон `DRONE` и `BOSS` Мега-Индюк с фазой ярости. Трупы поверженных кур опрокидываются с перьями и остаются на полу арены на 3.5 сек.
- **Информативный HUD 2.5**: тактический радар, счётчик оставшихся врагов в волне, цветное перекрестие в оттенок текущего ствола, плавная полоса прогресса перезарядки, полоса босса, 14 достижений и всплывающие цифры крит-урона.

### 3. Арсенал (12 стволов) и способности
- `1..7`: Пистолет, ПП, Штурмовая винтовка, Дробовик, Снайперка, Миниган, Гранатомёт.
- `8`: **RAILGUN** (сквозной электромагнитный луч), `9`: **PLASMA** (рикошетные сферы), `0`: **ARC CANNON** (цепная молния), `[` / `]`: **CRYO LANCE** (замедление цели) и **ION SAW** (энергодиск до 36 м).
- Гаджеты и перки: `[Z]` Грэппл-крюк (58 м), `[X]` Орбитальный удар «ЯЙЦЕГЕДДОН», `[G]` Кластерная граната, `[T]` Авто-турель «КУРОРЕЗ», `[V]` Удар крылом, `[ALT]` Рывок, `[B]` Магазин перков.

### 4. Встроенные локальные режимы (100% внутри C++)
- **`[P]` Симулятор парной «КОЧЕТ В БАНЬКЕ»** (`src/BanyaSim.h`): 3-минутные заходы без паузы, настенный термометр пара и снег за окном, **57 загадок** и **14 концовок** с боевыми баффами для Арены и кредитами `¤`.
- **`[J]` Нативное Казино** (`src/CasinoSim.h`):
  - **«Золотая Рулетка»** со всеми типами ставок (до `×36`) и историей последних 10 выпадений;
  - **`[TAB]` «Кибер-Слоты 777»** с 3 неоновыми барабанами и выплатами до `×50` (только виртуальные фишки `¤`, сохранение в `settings.ini`).
- **`[K]` Pixel Arcade — 6 мини-игр** (`src/ArcadeGames.h`):
  1. `[1]` **Змейка**
  2. `[2]` **Арканоид**
  3. `[3]` **Куро-Ран** (Dino)
  4. `[4]` **Pong vs ИИ**
  5. `[5]` **Flappy Кочет**
  6. `[6]` **Кибер-Тетрис** (все 7 тетромино, поворот, hard-drop, сжигание линий)

## Интерактивные 3D-столы и парная

- **Рулетка:** ЛКМ по сукну выбирает число 0–36 или внешнюю ставку
  (цвет, чётность, половина, дюжина, колонка). Фишка отмечает выбранную
  ячейку; `A/D` — номинал, `SPACE` — поставить и запустить колесо.
  Отдельное поле ставок открыто по умолчанию; `F` скрывает/показывает его.
  Каждый клик добавляет фишку выбранного номинала. Можно ставить одновременно
  на несколько чисел, цвета, дюжины и колонки; повторные клики увеличивают сумму
  на ячейке. `U` отменяет последнюю фишку, `C` очищает стол.
  `V` добавляет текущую ставку, выбранную через Q/E и W/S (в том числе
  сплит/стрит/корнер/сикс-лайн по существующим правилам якорного числа).
  На границах ячеек эти комбинированные ставки пока не выбираются.
  На столе видны общая сумма и суммы по стандартным зонам; комбинированные
  ставки входят в общую сумму. Корнер возвращает ×9, включая исходную ставку.
  Списание происходит при SPACE, все выплаты суммируются. Во время спина
  редактирование закрыто. При смене игры/выходе неоплаченные фишки снимаются.
  Лимит — 512 фишек и 1 000 000 ¤ за раунд; реальных платежей нет.
- **Блэкджек:** `B` переключает на отдельный 3D-стол. `SPACE` — раздать,
  `H/SPACE` — ещё, `N` — хватит, `X` — удвоить на первых двух картах.
  Действия доступны также через кнопки «Ещё», «Хватит», «Дабл».
  Колода — 52 карты, дилер стоит на soft 17, натуральный блэкджек — 3:2
  (дробная фишка округляется вниз), ничья возвращает ставку.
  Сплит и страховка пока отсутствуют. Выход во время раздачи автоматически
  завершает её как «хватит», повторного начисления нет.
- **Баня:** ЛКМ по печи/ковшу — пар, по венику — веник, по кадке — вода,
  по двери — проветривание. Действуют те же ограничения симулятора, что и
  для кнопок. Во время загадки взаимодействие с предметами блокируется.
- **Обзор:** удерживайте ПКМ и двигайте мышь горизонтально в бане/казино.

Сборщики Bash, PowerShell и новая конфигурация CMake теперь по умолчанию
генерируют 1024×1024 PBR-карты. 4096×4096 включается только через
`./build.sh --4k` или `./build.ps1 -Ultra4K`. Сукно, золото, медь и берёза больше не
ограничиваются 2048 в 4K-режиме. Текстуры создаются в каталоге сборки;
компактные исходные PNG в `Data` остаются 1024. Для слабого ПК на Linux:
`TEX_SIZE=1024 ./build.sh`. Для существующего CMake-кэша задайте
`-DTEX_SIZE=4096` и соберите цель `textures_4k`.
4K текстуры не меняют автоматически разрешение экрана на 3840×2160.

Все ставки — только на виртуальные фишки, без покупки и вывода.
Шесть игр Pixel Arcade по-прежнему используют пиксельный 2D-рендерер;
эта доработка касается 3D-казино и парной. Визуальную приёмку на GPU
(читаемость разметки, положение камеры, FPS и расход VRAM) нужно провести
на целевом ПК; увеличение текстур само по себе не гарантирует фотореализм.


### Если после обновления игра тормозит или перестала отвечать

1. Пересоберите обычный вариант: `./run.sh --rebuild --safe-mode`.
   Это заменит ранее сгенерированные 4K-текстуры на 1024 (если переменная
   `TEX_SIZE` не задана). Windows: `./build.ps1`, затем запустите
   `MyShooter.exe --safe-mode` из каталога сборки.
2. `--safe-mode` игнорирует тяжёлые сохранённые параметры: окно 1600×900,
   низкое качество, без MSAA, теней и постобработки, лимит 60 FPS.
   Файл настроек не удаляется; при следующем сохранении лёгкие настройки
   заменят прежние графические параметры. Игровой прогресс не сбрасывается.
3. Даже при оставшихся 4K PNG обычный высокий пресет теперь загружает
   уменьшенный mip-уровень, а низкий/средний — ещё меньший. Полное
   разрешение текстур доступно только в Ultra.

Выход из казино через Escape или кнопку доступен и во время вращения:
оплаченный спин завершается и рассчитывается один раз перед закрытием.


Разметка отдельного поля ориентируется на европейский single-zero layout:
https://www.hardrock.bet/casino/how-to-play-roulette/european-roulette/
Блики казино приглушены: Bloom отключён, цветные источники света больше
не пульсируют, шарик имеет неметаллическую поверхность. Это стилизация,
не точная копия конкретного казино. Проверка на целевом GPU всё ещё нужна.


### Минималистичный интерфейс мини-игр

Декоративные лозунги и повторяющиеся инструкции убраны. На поле рулетки
суммы показаны на текстурированных фишках, повторные ставки — стопкой
(до трёх видимых слоёв; точная сумма написана на верхней фишке).
Цвет обозначает диапазон общей суммы, а не номинал каждой фишки в стопке.
Тип/якорь комбинированной ставки и общая сумма остаются в панели управления;
комбинированные ставки не рисуются на границах ячеек.
Номинал новой фишки показан между кнопками −/+. Правила казино доступны
по кнопке `?`, без обязательного окна при входе. Горячие клавиши сохранены.
В бане остались шкалы, таймер, краткие предупреждения, загадки и итоги;
в аркадах — счёт, названия игр и необходимые игровые клавиши.

Атлас `Data/Textures/UI/CasinoChips.png` — 384×64 RGBA, около 12 КБ,
без внешних зависимостей: `python3 tools/gen_chip_atlas.py`.
Все 147 спрайтов стопок создаются один раз вместе с панелью и переиспользуются.

### Анимации казино и лимит 240 FPS

В настройках графики в строке FPS появился вариант **240 FPS**. Это лимит,
не гарантия производительности: VSync, частота монитора и GPU могут ограничить
реальную частоту. Старые сохранённые значения 60/120/без лимита не меняют смысл;
режим восстановления по-прежнему ограничен 60 FPS.

- Фишки летят от выбора номинала к ячейке; выигравшие зоны кратко подсвечиваются.
- Победа, проигрыш, возврат и крупный выигрыш имеют разные цвета и короткие
  анимации результата с пересчётом чистого итога. Частичная выплата меньше
  суммарной ставки считается проигрышем, а не победой.
- Новые карты раздаются с задержкой, закрытая карта дилера переворачивается.
- Все новые таймеры используют секунды. Ввод и выход не ждут завершения эффектов.
  Баланс рассчитывается сразу правилами игры: анимация чисел — только отображение.
- Пул полётов ограничен 24 спрайтами, движения карт — текущей раздачей.
  Во время спина весь интерфейс ставок больше не обновляется каждый кадр.
- Начальному меню возвращены подзаголовок с режимами и краткая подсказка выбора.

Проверки без GPU покрывают таймеры при 30/60/120/240 FPS, совместимость настроек
и классификацию результата. Визуальную проверку и замер 240 FPS на целевом ПК
нужно провести отдельно: раздача/добор/дабл, повторные быстрые клики, resize,
выход во время спина и новый раунд сразу после результата.
