# ЧТО ЭТО ЗА ХУЙНЯ?
ChickenGun — результат коллективной лоботомии разработчиков, проведённой в подвале ветеринарной клиники без анестезии и лицензии.
Проект создавался людьми, у которых медицинская карта толще исходного кода.
По неподтверждённым данным, после запуска игры у пользователей наблюдаются:
- Острая куриная недостаточность.
- Терминальная стадия долбоебизма.
- Хроническое желание стрелять по птицам.
- Прогрессирующая атрофия здравого смысла.
- Синдром фантомного яйца.
- Аллергия на нормальный геймплей.
Внимание: перечисленные заболевания вымышлены. Однако качество кода вызывает реальные вопросы.

- Пишет 600 строк в одной функции.
- Использует goto как философскую концепцию.
- Удаляет обработку ошибок ради производительности.
- Называет переменные a, aa, aaa, aaaa.
- Считает segmentation fault способом завершения программы.

- **Единая система критического урона, потолок комбо и ранг рейда (`S..F`)**:
  - `Cyber::ComputeShotDamage` + `Cyber::CritChanceFromPerks`: шанс крита растёт от перка *Вольфрамовый сердечник* (`6% + 3%/ур.`) с золотыми индикаторами `★ КРИТ!` в 3D-мире.
  - `Cyber::ComboMultiplier`: множитель серии ограничен потолком `×4.0` (исправлено бесконечное раздувание счёта).
  - `Cyber::RaidGrade` + учёт нанесённого/полученного урона: экран `GAME OVER` присваивает итоговый ранг рейда от `F` до `S`.
- **Бюджет частиц `Cyber::ClampParticleBudget` (`420` узлов)**: автоматическая очистка старейших осколков и перьев в `UpdateDebrisLite` защищает FPS на тяжёлых волнах.
- **Скачиваемая C++ поставка (`tools/package_linux.sh`, `CPack` и `.github/workflows/release-cpp.yml`)**: автоматическая упаковка автономного архива `CHIKENGUN-2.4-Linux-x86_64.tar.gz` (`$ORIGIN/lib`, `ChikenGun.sh`, `.desktop`, `SHA256SUMS.txt`) и облачная сборка нативного C++ бинарника в GitHub Actions / Releases.

- **`[8]` Квантовый Рельсотрон (`RAILGUN`)**: гиперзвуковой электромагнитный луч, прошивающий насквозь всех робо-кур и взрывоопасные бочки на линии выстрела с неоновым плазменным следом и кинематографичным slow-motion при мульти-фраге.

## Сборка

Что нужно:

- **Urho3D** (заголовки + `libUrho3D.so` / `libUrho3D.a`). `build.sh` ищет сборку в `$URHO3D_HOME` (по умолчанию `$HOME/urho3d_build`); свой путь можно задать вручную:
  `URHO3D_HOME=/путь/к/urho3d_build ./build.sh`
- SDL2 (`libsdl2-dev`), OpenGL/X11, `g++` с поддержкой C++17 и `pthread`.

```bash
./build.sh                 # соберёт генератор 4K PBR текстур, сгенерирует 4096×4096 карты в build/Data/Textures и соберёт build/MyShooter
TEX_SIZE=2048 ./build.sh   # опционально: ускоренная генерация текстур 2048×2048
```

## Запуск

Бинарник кладётся в `build/MyShooter`, ресурсы синхронизируются в `build/Data` и `build/CoreData`:

```bash
./build/MyShooter
```

## Настройки 4K

Меню → **«НАСТРОЙКИ 4K»** (14 параметров): общий пресет графики (*НИЗКИЙ / СРЕДНИЙ / ВЫСОКИЙ / 4K УЛЬТРА*), разрешение (*АВТО / 3840×2160 / 2560×1440 / 1920×1080 / 1600×900*), режим экрана (*Оконный / Без рамки / Полный экран*), сглаживание (*MSAA 2x/4x/8x + FXAA*), каскадные тени (*1K / 2K / 4K*), HDR + Bloom + CAS 4K резкость, SSAO 4K, VSync и лимит FPS, анизотропная фильтрация 16x, угол обзора FOV (`75°..105°`), чувствительность мыши, громкость эффектов и музыки. Все параметры сохраняются в XML `settings.ini` вместе с рекордом очков.

## Что за игра

CHIKENGUN — шутер про кур. Все противники — процедурные курицы четырёх пород
(белая клуша, рыжий петух-чарджер, чёрный стрелок, индюк-босс), собранные из
примитивов движка: тело-яйцо, гребень, клюв, крылья, веер хвоста, лапы.
Они ходят, клюют, хлопают крыльями и взрываются перьями. Игрок держит оружие
куриными крыльями.

Мега-арена 2.5 расширена до **416×416 м** (почти в 5 раз больше по площади): центральная площадь с голограммой, кольцо неоновых обелисков, **Восточный 3D-павильон Казино «Золотая Рулетка»** с вращающимся колесом на крыше, **Западный 3D-зал «Pixel Arcade»** с 6 неоновыми автоматами, **Северная эстакада** с пандусами и двумя снайперскими башнями, **Южный двухъярусный контейнерный порт**, 4 угловые цитадели, 12 гравитационных джамп-падов и 26 взрывоопасных бочек.

В игру встроены **20 единиц оружия** (включая Магнум, Автодробовик AA-12, Неоновый Арбалет, Огнемёт «Инферно», Тесла-пушку с цепной молнией, парные Узи, BFG-9000 и **4 боевых ножа**: Штык-нож M9, Керамбит, Нож-бабочка и Кибер-Катана с многосоставными процедурными анимациями), а также нативные C++ режимы **Казино «Золотая Рулетка & Слоты 777» `[J]`** и **Pixel Arcade `[U]`** (6 мини-игр: *Snake, Pong, Breakout, Flappy, Dino Run, Tetris* с заработком кредитов `₵`).
