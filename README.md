# CHIKENGUN2.1

Простое демо-приложение на движке **Urho3D** (C++).

## Описание
- Сцена с камерой, направленным светом и моделью куба (`Box.mdl`, текстура `Stone.xml`)
- Выход из приложения по клавише **ESC**

## Структура
- `main.cpp` — исходник приложения (MyApp)
- `build.sh` — скрипт сборки через g++ с линковкой Urho3D
- `bin/` — собранный бинарник `MyShooter` и данные CoreData/Data
- `src/` — исходники

## Сборка
```bash
./build.sh
```
Требуется установленный Urho3D (путь задаётся в `build.sh`).

## Запуск
```bash
cd bin && ./MyShooter
```
