# CHIKENGUN 2.5 — ПЕРО СУДЬБЫ (Native Desktop C++17 / Urho3D)

> **100% нативный кросс-платформенный C++17 / Urho3D 3D-шутер** (NixOS/Nix, Linux, macOS, Windows). Веб-версия полностью выведена из проекта — весь геймплей, 4K PBR-арена, интро 2.5.6, баня, казино со слотами 777 и все 6 мини-игр Pixel Arcade работают в едином нативном desktop-приложении.

## Быстрый старт на любой ОС

### Nix / NixOS
```bash
nix run                  # Flakes: собрать, проверить тесты и сразу запустить
nix develop -c ./run.sh  # Dev-окружение с готовым Urho3D 1.9.0 SDK
nix-shell --run ./run.sh # Классический nix-shell (без Flakes)
```

### Linux (Ubuntu/Debian, Fedora, Arch, openSUSE, Alpine, Void) и macOS (Intel / Apple Silicon)
```bash
git clone https://github.com/rapemaster1488/CHIKENGUN2.1.git
cd CHIKENGUN2.1
./run.sh --install-deps   # поставит системные пакеты, закэширует Urho3D 1.9.0 и запустит игру
```

После первого запуска:
```bash
./run.sh                   # мгновенный запуск (пересобирает только при изменении src/*)
./run.sh --4k              # собрать полный 4K UHD набор PBR-текстур (4096×4096) и запустить
./run.sh --diagnose-sdl    # Linux: проверить встроенный SDL, дисплей, OpenGL и аудио
./run.sh -nosound          # запустить без звука
./tools/package_linux.sh   # упаковать автономный .tar.gz для запуска на другом Linux без компилятора
```

Если окно не открывается, запускайте игру из графической X11/Wayland-сессии: без доступного дисплея подставной видеодрайвер не создаёт игровое окно. При отсутствии аудиоустройства Linux-клиент продолжит работу без звука. Диагностика и пересборка SDL описаны в [руководстве](docs/DESKTOP_BUILD.md#диагностика-sdl-на-linux).

### Windows (PowerShell / Visual Studio / MSVC)
```powershell
.\run.bat                  # соберёт/закэширует Urho3D 1.9.0 (OpenGL) и запустит MyShooter.exe
.\build.ps1 -Ultra4K       # текстуры 4096x4096
.\build.ps1 -TestsOnly     # быстрые C++17 модульные тесты
```

Подробнее о флагах и сборке через CMake с локальным Urho3D SDK — в [`docs/DESKTOP_BUILD.md`](docs/DESKTOP_BUILD.md).

## Что внутри нативного клиента CHIKENGUN 2.5 / 2.5.6

### 1. Кинематографичное интро (`koch.studios` → `powered by fall.os` → `CHICKENCUM 2.1`)
- Медленное посимвольное появление, золотые ореолы, световая волна, частицы и плавный переход к загрузке и меню. Заставка длится около 15,5 с под оригинальную осеннюю тему `Data/Music/KochSplashTheme.wav` ([подробнее](docs/SPLASH_INTRO.md)). Скип: клик / `Space` / `Enter` / `Esc`.

### 2. Боевая 3D-арена 256×256 «ПЕРО СУДЬБЫ»
- **Архитектура карты**: центральный ритуальный круг (циан + золото) с 4 взлётными световыми полосами, 4 диагональных hazard-ежа с коллайдерами, 2 неоновые арки-ворота (`z = ±40`), технический балкон, магистральные трубы с вентилями, 4 гравитационных джамп-пада и 3D-сруб **«Банька Смотрящего»**.
- **9 наборов PBR-текстур + Skybox4K IBL + Post-Process стек** (`SSAO4K` + `BloomHDR` + `Cinema4K` ACES Filmic & CAS + `FXAA3`), 4 пресета погоды с 3D-частицами (`[F8]`).
- **6 пород кур с живым ИИ**: `MELEE` (петляние восьмёркой при сближении + выпад клювом), `CHARGER`, `SHOOTER`, `KAMIKAZE`, летающий дрон `DRONE` и `BOSS` Мега-Индюк с фазой ярости. Трупы поверженных кур опрокидываются с перьями и остаются на полу арены на 3.5 сек.
- **Информативный HUD 2.5**: тактический радар, счётчик оставшихся врагов в волне, цветное перекрестие в оттенок текущего ствола, плавная полоса прогресса перезарядки, полоса босса, 14 достижений и всплывающие цифры крит-урона.

### 3. Арсенал (12 стволов) и способности
- `1..7`: Пистолет, ПП, Штурмовая винтовка, Дробовик, Снайперка, Миниган, Гранатомёт.
- `8`: **RAILGUN** (сквозной электромагнитный луч), `9`: **PLASMA** (рикошетные сферы), `0`: **ARC CANNON** (цепная молния), `[` / `]`: **CRYO LANCE** (замедление цели) и **ION SAW** (энергодиск до 36 м).
- Гаджеты и перки: `[Z]` Грэппл-крюк (58 м), `[X]` Орбитальный удар «ЯЙЦЕГЕДДОН», `[G]` Кластерная граната, `[T]` Авто-турель «КУРОРЕЗ», `[V]` Удар крылом, `[ALT]` Рывок, `[B]` Магазин перков.

### 4. Встроенные локальные режимы (100% внутри C++)
- **`[P]` Симулятор парной «КОЧЕТ В БАНЬКЕ»** (`src/BanyaSim.h`): 3-минутные заходы без паузы, настенный термометр пара и снег за окном, **57 загадок** и **14 концовок** с боевыми баффами для Арены и кредитами `¤`.
- **`[J]` Нативное Казино** (`src/CasinoSim.h`):
  - **«Золотая Рулетка»** со всеми типами ставок (до `×36`) и историей последних 10 выпадений;
  - **`[TAB]` «Кибер-Слоты 777»** с 3 неоновыми барабанами и выплатами до `×50` (только виртуальные фишки `¤`, сохранение в `settings.ini`).
- **`[K]` Pixel Arcade — 6 мини-игр** (`src/ArcadeGames.h`):
  1. `[1]` **Змейка**
  2. `[2]` **Арканоид**
  3. `[3]` **Куро-Ран** (Dino)
  4. `[4]` **Pong vs ИИ**
  5. `[5]` **Flappy Кочет**
  6. `[6]` **Кибер-Тетрис** (все 7 тетромино, поворот, hard-drop, сжигание линий)

## Управление

| Клавиша | Действие |
|---|---|
| `WASD` / `SHIFT` / `ALT` / `SPACE` / `C` | Движение / Спринт / Рывок / Прыжок / Присед |
| `ЛКМ` / `ПКМ` / `R` / `V` / `L` / `I` | Огонь / Прицел / Перезарядка / Крыло / Лазер / Осмотр |
| `1..9`, `0`, `[` / `]`, `TAB`, `Q/E` | Выбор из 12 стволов, 3D-арсенал, 10 PBR-скинов |
| `Z` / `X` / `G` / `T` / `B` | Крюк / Орбита / Граната / Турель / Перки |
| `P` / `J` / `K` | Банька / Казино (Рулетка + Слоты 777) / Pixel Arcade (6 игр) |
| `F` / `M` / `F1` / `F2` / `F3` / `F8` / `F9` / `F11` / `F12` | Тир⇄Арена / Музыка / Справка / Фото / Телеметрия / Погода / Качество / Экран / Скриншот |
